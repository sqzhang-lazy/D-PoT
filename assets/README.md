# Visual assets

Paper: [Dynamic Planning for LLM-based Graphical User Interface Automation](https://aclanthology.org/2024.findings-emnlp.70/), Findings of EMNLP 2024.

The figures were extracted from the [arXiv source archive](https://arxiv.org/src/2410.00467), retrieved on 2026-11-21. Their numbering and captions were checked against the published ACL Anthology paper. The PDFs are original source assets; PNGs are 2,400-pixel-wide renderings with the original content and colors preserved.

| --- | --- | --- | --- |

`banner.png` is a custom repository header rendered from `banner.svg`. Its planning loop is a schematic illustration, not an experimental result or a figure from the paper.

README images use standard Markdown with relative PNG paths. Keep `assets/` beside the root `README.md` when downloading or uploading the repository.
